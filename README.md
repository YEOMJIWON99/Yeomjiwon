# 염지원 포트폴리오 (초안)

HTML / CSS / JavaScript로 만든 정적 사이트입니다. 서버 없이 GitHub Pages에서 그대로 동작합니다.
작품·작가 노트·약력은 `data/` 폴더의 JSON 파일을 `fetch()`로 불러와 화면에 그립니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(예: `portfolio`)를 만듭니다. (Public, 가능하면 염지원 본인 계정)
2. 압축을 푼 폴더 **안의 내용물 전체**를 저장소 맨 위에 올립니다. `index.html`이 맨 위에 있어야 하고, `assets` 폴더도 함께 올라가야 합니다.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택하고 Save 합니다.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/<저장소명>/` 주소로 접속됩니다.

## 공개하기 전에

`data/profile.json`의 `"draft": true`를 `false`로 바꾸면 화면 왼쪽 아래의 "초안 미리보기" 표시와 약력의 "추가 예정" 칸이 사라집니다.

## 내용 수정하기 (`data/` 폴더)

| 파일 | 내용 |
|---|---|
| `profile.json` | 이름, 한 줄 소개, 표지 사진(`heroImage`, 파일은 `assets/hero.webp`), 문의 종류(`inquiries`), 이메일, 인스타그램, 포트폴리오 PDF 경로 |
| `works.json` | 연작 목록(`series`)과 작품 목록(`works`): 제목, 연도, 재료, 크기, 소개, 이야기, 사진 |
| `statement.json` | 작가 노트 |
| `cv.json` | 학력, 자격, 전시, 수상 |

## 작품 사진 교체하기

1. 원본 사진을 긴 변 2400px 정도의 WebP 또는 JPG로 줄입니다. (한 장당 500KB 이하 권장)
2. `assets/works/` 폴더에 같은 이름으로 덮어쓰거나, 새 파일을 올리고 `works.json`의 `"src"`를 바꿉니다.
3. 목록용 작은 사진(`thumb`)은 긴 변 700px 정도로 `assets/works/thumbs/`에 넣습니다.
4. 흰 배경에 오려 낸 사진이면 `"cutout": true`, 배경까지 찍힌 사진이면 `"cutout": false`(또는 삭제)로 둡니다. `true`이면 흰 배경이 사이트 배경색과 자연스럽게 섞입니다.
5. 작품 한 점에 사진을 여러 장 넣으려면 `"images"`에 항목을 더 추가합니다. (예: 〈시지프스〉의 외부와 내부)
6. 새 작품은 `"works"` 목록에 항목을 하나 더 추가하면 됩니다. 순서는 목록 순서 그대로 보입니다.

〈탄생〉은 논문 PDF에 사진이 비어 있어 `"images": []`로 두었습니다. 사진을 받으면 위와 같은 형식으로 추가하세요.

## 확인이 필요한 항목

- 〈탄생〉 사진 (현재는 "사진을 준비하고 있습니다"로 표시)
- 〈유출 연작 — 사람〉 크기: 논문 도판 목록에는 5×15cm로 표기되어 있어 15×15cm로 넣었습니다.
- 학부 졸업연도, 대학원 입학·졸업(예정) 연도 (`cv.json`)
- 전시: 〈목금토전〉 개최 연도·장소, 갤러리 강호·갤러리 앨리 전시명과 연도, 단체전/개인전 구분 (`cv.json`)
- 수상·선정 이력 (`cv.json`, 지금은 비어 있음)
- 작가 노트와 한 줄 소개("상처를 담고, 시간을 들여, 싹을 틔웁니다.") 문구: 논문을 바탕으로 쓴 초안입니다.
- 〈탄생〉·〈노화〉가 〈씨앗 연작〉에 속하는지 (`works.json`의 `"series"`)
- 논문 심사 전에 논문 내용을 공개해도 되는지

## 내 컴퓨터에서 미리보기

`index.html`을 더블클릭하면 브라우저 보안 때문에 JSON을 불러오지 못합니다. 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`으로 여세요.

```
python -m http.server 8000
```

## 이미지 출처

현재 들어 있는 사진은 논문 PDF에서 추출한 임시본입니다. 압축이 강하게 되어 있으므로 공개 전에 원본으로 교체하세요. 논문 속 박물관 소장품과 다른 작가의 사진은 저작권 때문에 사이트에 넣지 않았습니다.
